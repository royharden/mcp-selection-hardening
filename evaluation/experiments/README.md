# Draft pilot artifacts

This directory holds approval-needed development-pilot designs and summaries of
explicitly supplied pinned evidence. No experiment has run during construction.
No measured results, provider identity, price, token-fit proof or spend receipt is
supplied by these templates. A draft is not a dispatchable ExperimentManifest.

The future `scripts/pilot.py` planner writes new JSON drafts here only. Numeric
metric editions and README results remain exclusively owned by `scripts/eval.py`.
Replay evidence stays labeled and is never counted as live-model evidence.
