# Adapter activation boundary

Replay, keyword and abstain selectors are deterministic development controls. Replay preserves supplied raw argument strings, including malformed arguments, and is always labelled scripted. Keyword ties use stable lexical tool IDs; it does not read gold labels. Provider task projection is allowlisted. No environment key values are read on module import.

`LIVE_ARM_SLOTS` declares OpenAI GPT and Anthropic Claude family configuration slots with environment-variable names only. `LiveArm` requires a later exact model. `LiveSelector` checks explicit authorization/provider/model/family, price hash, corpus seal and budget reservation. It preserves ordered provider tool-call IDs separately from server IDs, reconstructs assistant tool-use/result history, rejects unmatched results, and caps the source path at three turns/six calls. A user-supplied Python approval dict is a trusted runner input, not an independently authenticated spending receipt.

`transports.OpenAIChatTransport` implements non-streaming OpenAI-compatible Chat Completions tool calls; `AnthropicMessagesTransport` implements Messages client-tool use. Each receives a credential callback, endpoint and explicit `network_enabled` flag (false by default); Anthropic additionally needs an approved API version. No key values are read on import. Redirects are refused, response bytes are capped, and HTTP code never retries itself. OpenAI argument strings are retained exactly as returned; Anthropic input objects are retained as raw lexical JSON slices from the provider response. That inherent wire-format difference must be included in golden parity review. These adapters do not execute selected tools.

`live.BudgetedLiveTransport(wire_transport,ledger,approval,prices,token_counter,journal)` connects to the selector. Approval requires Dirty Mode closure, live/network authority, exact provider/family/model/endpoint, dated prices, corpus seal, budget reservation, token-counter version, and request/input/output bounds. The injected counter must count the complete provider wire body, tools/history and overhead before reservation. The controller reserves both attempts' worst-case cost before send when one transient retry is enabled; starts the attempt before HTTP; journals private request/response evidence outside public results; records identity, IDs, raw hashes, usage and settlement references; and keeps unknown usage reserved on failure/cancellation/restart. Only transient network/429/5xx failures can receive one retry. Semantic invalidity, truncated content, identity drift, observer problems and refusal do not receive semantic retries. No retry uses a successful alternative model.

`DatedTokenPrices` contains approved integer microunits-per-million rates and computes conservative request reservations and dated token-price estimates. Estimates are explicitly labelled, not asserted to be provider invoices. Missing usage or unpriced cache-token categories remain unknown. Full billed-cost reconciliation is later activation work. The controller exposes `attempts`, `last_response` and `cost_summary()` for runner records, including unsuccessful attempts; unknown costs never become free. A credential failure after attempt admission conservatively retains its reservation.

Official source references consulted during construction (2026-10-23): [OpenAI Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create), [Anthropic Messages API](https://platform.claude.com/docs/en/api/messages/create), [Anthropic client tool lifecycle](https://platform.claude.com/docs/en/agents-and-tools/tool-use/handle-tool-calls). Models, dates/prices, API version, credentials, runtime token counting and authority remain unset. No live evidence, costs, provider request or successful interoperability have been measured; source inspection and syntax parsing are the only construction checks.
